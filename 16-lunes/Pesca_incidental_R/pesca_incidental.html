Introducción

Los peces de pico o “picudos” (marlines, pez espada, pez vela, etc.) son capturados de manera incidental durante las operaciones de pesca que tienen como especie objetivo a los atunes. Analizaremos la base de datos de la flota cerquera que opera en el Océano Pacífico Oriental Tropical. Estos provienen del programa de observadores a bordo de la flota y son compilados por la Comisión Interamericana del Atún Tropical (CIAT o IATTC, por sus siglas en inglés).

Esta base de datos y otras están disponibles en la página: https://www.iattc.org/es-ES/Data/Public-domain.

De acuerdo con el documento PSBillfish-Picudos.pdf que también se encuentra en data, se tiene información de tres tipos de lances de pesca (SetType):

  1. realizados sobre manadas de delfines (DEL)

  2. sobre objetos flotantes (OBJ)

  3. sobre cardúmenes de atún no asociados (NOA).

Están agregados en cuadrantes 1º \(\times\) 1º de longitud-latitud y por mes desde 1993 hasta diciembre de 2025. Para cada cuadrante/año/mes se conoce el número de lances realizados (NumSets), que sería una medida del esfuerzo pesquero y las capturas de varias especies en número de individuos capturados. Las especies corresponden al marlin negro (BLM, Istiompax indica); marlin azul (BUM, Makaira nigricans); marlin rayado (MLS, Kajikia audax); pez vela (SFA, Istiophorus platypterus); marlin trompa corta (SSP, Tetrapturus angustirostris) y pez espada ( SWO, Xiphias gladius). En el código BIL se incluyen aquellos individuos que no lograron identificarse.

Para este tutorial vamos a concentrarnos en los últimos seis años.

pic <- pic[pic$Year > 2019, ]

Ahora necesitamos un mapa. Lo podemos importar de la base GSHHG (A Global Self-consistent, Hierarchical, High-resolution Geography Database; https://www.soest.hawaii.edu/pwessel/gshhg/). En la carpeta data/gshhg se incluye esta base en baja resolución.

# Funcion para convertir a Poligonos espaciales
PolySet2SpatialPolygons <- function(PolySet){
  require(sp)
  PS <- PolySet
  if (!inherits(PS, "PolySet")) 
    stop("not a PolySet object")
  
  coords <- as.data.frame(PS[, c('X', 'Y')])
  poly_coords <- split(coords, PS$PID)
  
  # Create a list of Polygon objects
  polygon_list <- lapply(poly_coords, function(coords) {
    Polygon(coords)})
  
  # Create a Polygons object
  polygons <- Polygons(polygon_list, ID = "polygons")
  
  # Create a SpatialPolygons object
  spatial_polygons <- SpatialPolygons(list(polygons))
  spatial_polygons
}

El marlin azul (BUM) es la especie más capturada, especialmente en lances sobre objetos flotantes, por lo que filtraremos nuestros datos para esta especie y tipo de lance.

BUM <- pic[pic$SetType == "OBJ", 
           c('Year', 'Month', 'LonC1', 'LatC1', 
             'NumSets', 'BUM')]

BUM <- aggregate(BUM[, c(5, 6)], list(lon = BUM$LonC1, 
                                      lat = BUM$LatC1,
                                      mes = BUM$Month), sum)

Preparamos los datos por mes para representarlos en un mapa,

BUM$cipue <- BUM$BUM/BUM$NumSets

# para cada mes
for(i in 1:12){
  x <- BUM[BUM$mes == i, c(1, 2, 6)]
  x <- data.frame(EID = 1:nrow(x), x)
  names(x)[2:4] <- c("X", "Y", "Z")
  class(x) <- c("EventData", "data.frame")  
  assign(paste0("BUM.", i), x)
}
